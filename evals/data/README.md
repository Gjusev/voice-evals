# Replay datasets

## `demo_calls.jsonl` (v0.1, unchanged)

The original three-call demo shipped with v0.1.0/0.1.1. Its expected metrics
are asserted by `tests/test_core.py` and must never change:

- samples=3, mean_wer = (1/11)/3, task_completion = 2/3, fact_coverage = 5/6,
  hallucination_rate = 1/3, e2e_p50 = 950 ms, median barge-in stop = 210 ms.

## `replay_v02.jsonl` + `replay_v02.expected.json` (v0.2 regression corpus)

**This is harness regression data, not evidence of live model quality.**

- 123 rows: 3 hand-checked calls + 120 synthetic calls (40 appointment, 40
  support/rescheduling/cancellation, 40 controlled fault/edge cases).
- Deterministically generated by `scripts/gen_replay_corpus.py` with seed
  `20260211`. Regenerate only via that script; never hand-edit rows.
- Coverage by construction: substitutions, deletions, insertions, empty
  hypotheses, WER above 1, successful and failed outcomes, fact omissions,
  forbidden phrases, latency tails, absent optional stage timings, and
  measured/unmeasured interruption stops.
- `replay_v02.expected.json` freezes aggregate metrics for the documented
  regression gate and records the hand-checked WER cases:

  | id | truth | hypothesis | hand-derived WER |
  | --- | --- | --- | --- |
  | call-hand-001 | "book a table for four" | "book a table for or" | 1 substitution / 5 words = 0.2 |
  | call-hand-002 | "cancel my order" | "cancel my order please now" | 2 insertions / 3 words = 2/3 |
  | call-hand-003 | "yes" | "no yes maybe" | delete "no" + insert "maybe" = 2 edits / 1 word = 2.0 (> 1) |

  These per-call values were computed by hand from word edit distances, so the
  expected outputs are not merely produced by the implementation under test.

### Limits

- All transcripts/outcomes are synthetic. No provider, model, or human caller
  produced them. Latency numbers cover parser/aggregation behavior only.
- Interruption `agent_stopped_ms: null` rows exercise the "unmeasured stop"
  path; the median over measured stops must not be read as a stop-rate.
- Dataset SHA-256 (frozen at generation time) is recorded in the bundle
  manifest produced by `scripts/build_kaggle_bundle.py`.
